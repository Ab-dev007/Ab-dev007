## Selected projects

### [Shakespeare Language Model](https://github.com/MindForge-Abhishek/shakespeare_lm)

A character-level language model built from scratch in PyTorch, progressing from a bigram baseline to a GPT-style transformer on Tiny Shakespeare.

- Implemented causal multi-head attention, positional embeddings, residual connections, and feed-forward blocks.
- Built a training workflow with validation, dropout, gradient clipping, and checkpointing.
- Documented the architecture, experiments, and sample text generation alongside learning notebooks.

`Python` `PyTorch` `Transformers` `Jupyter`

### [Codeforces MCP Server](https://github.com/MindForge-Abhishek/Codeforces_mcp)

A Python MCP server that connects Claude to Codeforces, making submission review and competitive programming problem logging easier.

- Exposes six tools for submissions, user profiles, rating history, standings, and contests.
- Uses asynchronous HTTP requests to retrieve public Codeforces data.
- Keeps problem details available in the conversation so reflection can focus on the approach and lessons learned.

`Python` `MCP` `httpx` `API integration`
